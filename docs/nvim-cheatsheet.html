    注意事項

    Swap 檔提示（E325）

    注意nvim 沒有正常離開（例如直接關掉 pane）時，未存的修改會留在 swap 檔，下次開到同一個檔案會跳出提示：
    • 按 D 刪掉 swap 檔，R 復原當時的修改。
    • grn 改到有殘留 swap 檔的檔案時無法回應提示，會直接報錯。先清掉殘留的 swap 檔再 rename。
    • 離開前用 :wqa 或 :qa!，不要直接關 pane，就不會留下 swap 檔。

    和 herdr 的關係

    herdr 不按 prefix 時只攔 Ctrl-b（它的 prefix），其餘 herdr 快捷鍵都要先按 prefix，所以這份設定的按鍵不會被 herdr 攔走。

    選項

    選項說明
    clipboard=unnamedy / p 直接用系統剪貼簿
    nowrap、number、cursorline、scrolloff=5從 .vimrc 搬過來
    ignorecase + smartcase搜尋不分大小寫，打了大寫才區分
    tabstop=2、shiftwidth=2、expandtab2 空格縮排
    updatetime=250游標停住 250ms 就觸發 CursorHold（預設 4 秒），讓 symbol 標示即時出現
    confirm有未存檔的 buffer 時，:q 會詢問要不要存，而不是噴 E37
