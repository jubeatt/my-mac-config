其他

Swap 檔提示（E325）

nvim 沒有正常離開（例如直接關掉 pane）時，未存的修改會留在 swap 檔，下次開到同一個檔案會跳出提示：
  • 按 D 刪掉 swap 檔，R 復原當時的修改。
  • grn 改到有殘留 swap 檔的檔案時無法回應提示，會直接報錯。先清掉殘留的 swap 檔再 rename。
  • 離開前用 :wqa 或 :qa!，不要直接關 pane，就不會留下 swap 檔。

和 herdr 的關係

herdr 不按 prefix 時只攔 Ctrl-b（它的 prefix），其餘 herdr 快捷鍵都要先按 prefix，所以這份設定的按鍵不會被 herdr 攔走。
