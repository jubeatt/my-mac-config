Swap 檔提示（E325）

注意nvim 沒有正常離開（例如直接關掉 pane）時，未存的修改會留在 swap 檔，下次開到同一個檔案會跳出提示：
  • 按 D 刪掉 swap 檔，R 復原當時的修改。
  • 提示裡寫 STILL RUNNING 時，代表另一個 nvim 還開著這個檔案，例如別的 pane，或在 shell 背景暫停的 nvim。這時 swap 檔刪不掉，從 fzf-lua 開檔會報 Unable to add buffer。暫停的 nvim 用 jobs 找出來，fg 叫回來後用 :wqa 離開。
  • grn 改到有殘留 swap 檔的檔案時無法回應提示，會直接報錯。先清掉殘留的 swap 檔再 rename。
  • 離開前用 :wqa 或 :qa!，不要直接關 pane，就不會留下 swap 檔。

which-key 面板裡的提示

面板列的都是目前真的存在的按鍵，來源有三種：

  • 這份設定加的：說明取自 init.lua 裡每個 keymap 的 desc，例如 Next git hunk。
  • Neovim 內建的 keymap：有些沒寫說明，就直接顯示它執行的指令，例如 ]q 顯示 :cnext、]b 顯示 :bnext。
  • which-key 自帶的 preset：替 Vim 內建 motion（]m、]s、]%…）補上說明。preset 裡的 ](、]{、]<、[< 是 Vim 沒有的按鍵，init.lua 把它們隱藏，面板列的是真正的 ])、]}。
補充很多 ] / [ 按鍵要有對應的清單才會動，沒有時按了像是沒反應：
  • ]q / ]l：quickfix / location list 裡要有東西，例如從 fzf 選單按 Alt-q 送出的結果。
  • ]b：要開了兩個以上的 buffer。
  • ]a：argument list，只有用 nvim a.ts b.ts 一次開多個檔案時才有。
  • ]t / ]<C-T>：tag 跳轉，要有 tags 檔，這份設定用不到。
  • ]s：要先 :set spell 開拼字檢查。
  • ]m / ]M：依大括號找 Java 風格 class 裡的 method，JS / TS 裡常跳不準。

搬檔與 imports

在 nvim-tree 用 r 改名或輸入新路徑、用 x / p 剪下貼上，或用 Space f m（:Mv）搬移目前檔案時，nvim-lsp-file-operations 會請 LSP 更新引用路徑。TypeScript 7 支援檔案與資料夾改名，也會調整搬走檔案內自己的相對 import。

  • 專案的 LSP 必須已啟動，並支援檔案改名請求；其他語言的行為依各自的 server 而定。
  • 其他引用檔案即使原本沒開啟，也可能被載入並修改；用 :wa 儲存所有修改過的檔案。
  • 這個串接只處理 nvim-tree 和 :Mv 的檔案操作；在 Finder 或終端機搬檔時不會透過這條流程更新 imports。

拼字檢查（CSpell）

nvim-lint 在開檔、存檔與離開 Insert mode 時，呼叫 CSpell CLI 非同步檢查目前 buffer，包含尚未存檔的文字。適用於 JS / TS / JSX / TSX、HTML / CSS / SCSS / Vue、JSON / YAML、Markdown / MDX、純文字、Git commit 訊息、Lua、Python 與 Shell。

  • 錯字以 cspell 來源出現在 diagnostics；用 ]d / [d 跳轉，Space x d 看目前檔案的清單。
  • Space x s 立即重新檢查；專案字庫或忽略規則修改後也可用。
  • 從目前檔案的資料夾向上尋找 CSpell 設定，例如 cspell.json、.cspell.json 或 .vscode/cspell.json；加入 words 可接受專案術語，ignorePaths 可排除檔案。
  • VS Code 的 cSpell.userWords 屬於編輯器設定；要讓兩邊共用自訂字詞，請放進專案的 cspell.json。
  • CSpell CLI 是必要的外部工具，由 Brewfile 的 npm "cspell" 安裝；使用目前啟用的 Node.js 全域環境。

Lazygit 與 Neovim

在 Neovim 按 Space g g，會在新分頁開啟目前 Git repo 的 Lazygit，直接進入可操作的 terminal mode。Herdr 裡的 Neovim 也適用。

  • 在 Files 或 commit 的檔案清單選檔後按 e，透過 nvim-remote 在同一個 Neovim 的新分頁開啟檔案；在 diff 裡按 e 可跳到對應行。
  • 按 Lazygit 的 q 離開，terminal 分頁會自動關閉，回到編輯畫面。
  • 在一般終端機直接執行 lazygit 時，e 會啟動 Neovim；離開編輯器後回到 Lazygit。
  • 編輯器選擇由 的 os.editPreset 設定，不需額外 Neovim 外掛。

和 herdr 的關係

herdr 不按 prefix 時只攔 Ctrl-b（它的 prefix），其餘 herdr 快捷鍵都要先按 prefix，所以這份設定的按鍵不會被 herdr 攔走。
